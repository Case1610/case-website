# ロゴタイプ案（Issue #4）

**これは私（Claude）の判断で出した案。** 本人の選択から導いたものではない。

## なぜマークを作らないか

第1〜5案のマークが全部落ちた原因は、探索が足りなかったからではない。
**マークにやる仕事が無いから。**

マークは「名前を出せない場所」で名前の代わりをするためにある。
製品の筐体、看板、グッズ、複数プロダクトの親。
このサイトにはそれが無く、**名前はいつでも出せる**。

だから毎回、形そのものではなく説明で支えることになった。
説明が要る記号は、仕事のない記号である。

前回「マーク無し」と言ったのは不正確だった。ファビコンは要る。
正確には **別のマークを作らず、ロゴタイプから1文字を切り出す。**

## 案

`sheet.html` をブラウザで開く（IBM Plex Mono を埋め込み済み）。

| | 内容 |
|---|---|
| 01 | 素の Medium。まだ「設定しただけ」 |
| **02** | **SemiBold・字間 −.05em。本命** |
| 03 | 全部小文字。lower case であること自体が意味を持つ |
| 04 | 全部大文字。看板になる |
| 05 | Show を細く Case を太く。重心を太さで言う |
| 06 | `case` 単独。リポジトリ名の系とは揃うがサイト名とズレる |
| 07 | 字間の振り。等幅のロゴタイプはここがほぼ全部 |
| 08 | `show` / `case` を縦積み。**両方4文字なので 4×2 の格子に揃う** |

08 は狙って作ったものではなく、等幅で組んだら出てきた。
この名前とこの書体でしか起きない。

## 書体

IBM Plex Mono（本人決定。判断基準は「どこでも使いやすいこと」）。
ロゴタイプとして確定するなら、字間を詰めた状態でアウトライン化して
1つの SVG にする。既製書体をそのまま置く状態では、他と同じ見た目になる。

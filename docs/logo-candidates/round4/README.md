円から組み直した。

## 見つけた構造 — c・a・e は同じ円である

```
   円環（リング）
     ├ 右を開ける          → c
     ├ 右に縦棒を足す      → a（1階建て）
     └ 横棒を入れて右下を開ける → e

   半径を半分にした輪を2つ、上下で向きを変える → s
```

**4文字は別々の形ではなく、ひとつの円に対する4つの操作。**
`blueprint.svg` はその導出をそのまま図にしたもので、**書体と同じ関数から描いている**
（形を直せば図も直る）。

線の太さ `W = R / φ²`、開口 `AP = R × 0.9`、字間 `= W × 1.4`。

サイズで使い分ける組にしてあるのは前案と同じだが、今回は**同じ書体の同じ文字**なので、
大小の関係が「省略」ではなく「開き具合」になっている。

## ルビンの杯は、まだできていない

`M8.svg` が試したもの。**閉じた輪の右側を白い `a` で抜き、抜いた形が a、残った形が c**
——「ひとつの切り欠きが両方の輪郭を兼ねる」を狙った。

**読めない。** 白い a が輪をまたぐと、輪の残りが三日月になって c に見えず、
a の側も輪に食われて a に見えない。**両方が同時に成立する位置が、この2つの形には無い。**

ルビンの杯が成立するのは、**杯と横顔がどちらも「輪郭線だけで決まる」形**だからで、
c と a はどちらも**面の太さ**を持っている。太さのある形を隣り合わせると、
片方の太さがもう片方の余白を食う。ここが今回いちばん分かったこと。

成立させるなら、たとえば以下のどれかが要る。

- 太さを持たない形（輪郭だけの線画）にする
- 2つの読みを**別の向き**に置く（上下反転で別の字になる、など）
- 同じ輪郭を、**図と地ではなく正負の空間**で共有する（M3a の方向）

# ロゴ 第3案 — 図と地、そして構成の根拠（Issue #4）

第2案への指摘（2026-09-13）:

> なんでそのロゴで決定しようとしているかわからないけど、そこまでは私も考えていて
> もう少しひねってほしい。図と地の関係を上手く使うとかするアイデアとかも欲しいし、
> ブループリントっぽかったり黄金比を利用したのとかも良いなと思っている。

第2案は**箱を描いて、その中に文字を入れただけ**だった。形が意味を持っておらず、
寸法にも根拠が無かった。作り直した。

## 考え方 — 置くことではじめて名前になる

**箱（外枠）と中身（内側の面）は同じ色。そのあいだにできた白い隙間だけが C の形をしている。**

```
  空の箱          置くと
  ┌─────┐        ┌─────┐
  │     │   →    │ ┌──┐│     ← 白いのは「隙間」
  │     │        │ │  ├┤        その隙間が C の形になる
  └─────┘        └─┴──┘
   ただの四角      C が現れる
```

中身を抜くと、隙間はただの四角に戻って C は消える。
**何も置かなければ名前にならない。** サイトの目的（証拠を置く場所）がそのまま形になっている。

右側で隙間が途切れ、そこで中身が箱につながる。
これが**仕立ての合わせ目**であり、同時に **C の開口部**でもある。
ひとつの切れ目が両方の役をしている（第2案では別々の装飾だった）。

さらに、白抜きの CASE は**ステンシル**にしてある。
ステンシルは、閉じた面（A の中の三角）が地から切り離されないように、
わざと線を切る書体である。**箱と中身の関係と、同じ問題を解いている。**
A の横棒の切れ目は装飾ではなく、この構造の要請。

## 寸法はすべて φ から連鎖で出す

| 記号 | 式 | 値 | 何か |
|---|---|---|---|
| `A` | — | 1000 | 外形の一辺。すべての出発点 |
| `H` | `A / φ` | 618 | 中身の一辺・文字の高さ |
| `M` | `(A − H) / 2` | 191 | 箱の壁の厚み |
| `S` | `H / φ³` | 146 | 線の太さ |
| `TAB` | `H / φ²` | 236 | 合わせ目（C の開口） |
| `LW` | `H / φ` | 382 | 走る文字の幅 |
| `GAP` | `S / φ` | 90 | 字間 |

φ = (1 + √5) / 2 = 1.6180339887…

**中間の値を手で決めていない。** 1000 を入れると残りが全部決まる。
比を後から動かしたくなったら、変えるのは φ の指数だけ。

## 設計図はロゴと同じ定数から生成する

`blueprint.svg` は `system.mjs` の定数を読んで描いている。
別々に描くと、片方を直したときにもう片方が嘘になる
（このリポジトリ群で4回踏んでいる形。docs/status.md と Issue #9 参照）。

**この設計図自体がサイトに置ける「証拠」でもある。**
出来上がりだけ見せると「センスで描いた」と読まれるが、
導出を並べれば、観察・比較の跡がそのまま残る。

## ファイル

| ファイル | 何か |
|---|---|
| `system.mjs` | **正本。** φ の連鎖と、マーク・文字の形を定義する |
| `blueprint.mjs` | 設計図を生成する |
| `usage.mjs` | ライト／ダーク用の書き出し |
| `mark.svg` / `u-mark-dark.svg` | マーク（ライト／ダーク） |
| `mark-empty.svg` | 中身を抜いた状態。C が消えることの確認用 |
| `u-lockup-light.svg` / `u-lockup-dark.svg` | マーク＋ CASE |
| `word-reversed.svg` | 白抜きの CASE 単体 |
| `blueprint.svg` | 設計図 |

再生成:

```sh
cd docs/logo-candidates/round3
node system.mjs && node blueprint.mjs && node usage.mjs
```

## 実測

| 見たもの | 結果 |
|---|---|
| マーク 16px | C が読める（隙間が3ピクセル残る） |
| ロックアップ 高さ32px（ヘッダーの実寸） | CASE が読める |
| ダーク配色 | 図と地が入れ替わるが、箱・中身・隙間の関係は変わらない |

## まだ決まっていないこと

- **ヘッダーをどうするか。** いまは 32px のロゴ ＋ 「ShowCase」というテキスト。
  ロックアップを置くと CASE が二重になる。第2案の README に3つの選択肢を書いてある
- **色。** いまは1色（インク）だけで成立している。ブランド色を差す場所は
  `mark-brand.svg` に候補があるが、**無くても成り立つ**ので、足す理由が要る
- **動き。** 「空の箱 → 置くと C が現れる」は2状態あるので、
  読み込み時やホバーで見せられる。やるかどうかは別の判断

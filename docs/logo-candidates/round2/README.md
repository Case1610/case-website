# ロゴ 第2案（Issue #4）

本人の指示（2026-09-13）:

> C の感じで A の箱を表現したい。んで、その箱を B 仕立てるような感じだと良いと思ってる。
> より抽象度が高くてもいい。CASE の文字が入っていたほうがいい。

## 3つを1つの形にまとめた

3案を並べるのではなく、**同じ形が3つの意味を同時に持つ**ようにした。

```
  ┌──────────┐
  │          │      ← 箱（A: 証拠を置く場所）
  │          ▌      ← 右壁の欠け。中身の高さぴったり
  │          │         （B: 中身に合わせて仕立てた開口部）
  └──────────┘
       ↑
  開口部があるので C にも読める（C: 頭文字）
```

**切り欠きを「角を落とす」から「中身の形に合わせて壁を欠く」に変えた。**
第1案の45°の角落としは、由来は仕立てだったのに**角折れの書類アイコンに見えていた**。
壁の一部が中身の高さぶんだけ欠けている形なら、「この中身のために開いている」と読める。
`Tailor to the Case` の直訳に近い。

## 4つの形

| ファイル | 何か | どこで使うか |
|---|---|---|
| `mark.svg` | 箱＋開口部だけ。文字なし | ファビコン、32px のヘッダー、小さいところ全部 |
| `case-inside.svg` | 開口部の高さ＝文字の高さ。**CASE が中身** | 48px 以上 |
| `case-stacked.svg` | 箱の中に CASE を2段。開口部には中身が嵌まっている | 48px 以上 |
| `lockup.svg` | マーク＋ CASE の横並び | ヘッダー、名刺、OGP |

## 構造的な問題（先に言っておく）

**16px でも 32px でも、CASE の4文字は絶対に読めない。**
いまヘッダーのロゴ枠は 32px、ファビコンは 16px。ここに文字を入れても潰れる。

だから「文字入りを1つ選ぶ」ではなく、**大きさで使い分ける組**にしてある。

- 小さいところ → `mark.svg`（文字なし）
- 大きいところ → `lockup.svg` または `case-inside.svg`

開口部の形が両方に共通なので、同じものだと分かる。

## ヘッダーをどうするか（未決・本人の判断）

いまヘッダーは **32px のロゴ ＋ 「ShowCase」というテキスト**。
ロックアップを置くと CASE が二重になる。3つの選び方がある。

| 案 | ヘッダーの見え方 | 言っていること |
|---|---|---|
| **そのまま** | マーク＋「ShowCase」 | 現状維持。マークだけ差し替える |
| **ロックアップ単体** | マーク＋CASE | サイト名が `CASE` になる。`ShowCase` を名乗らなくなる |
| **Show ＋ マーク** | 「Show」＋マーク | **マークが `Case` を担い、読むと ShowCase になる。** `case` の多義（事例／容れ物／姓）がそのまま効く |

3つめが構造としては一番きれいだが、**マークを読ませる前提**なので、
初見の人には「Show」だけが目に入る危険がある。

## 作り方

`generate.mjs` が SVG を書き出す。文字は `<text>` ではなく水平・垂直のストロークだけで
組んだ幾何ステンシルで、フォントに依存しない（どの環境でも同じ形になる）。

色は2色（インク＋ブランド `oklch(55% 0.17 265)`）。採用時は `currentColor` に寄せる。

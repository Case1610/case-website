### ここで分かったこと

**GitHub のアバターは丸く切り抜かれる。** 四角い枠を持つ案は、そこで枠の角が落ちて
別物になる。四角い枠を土台にする案は、この一点で不利。

**16px ではどの案も C に読めない。** 拡大したときの「読める／読めない」は、
実際に使われる大きさでは判断材料にならなかった。

ワードマークだけの案（D）を並べたのは、比較のため。
「盛らない」を芯にするサイトで、意味を主張する記号が要るのかは未決。

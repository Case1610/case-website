# ロゴの候補（Issue #4）

**まだ何も差し替えていない。** サイトのロゴは `public/caselogo.svg` のまま。

## コンセプトは新しく考えていない

既に決まっていることから引いた。ロゴは足す記号ではなく、既にある判断を
一枚の形に畳むものなので、ここで新しい意味を発明すると、サイトの中で
そこだけ由来のわからない絵になる。

引いた材料:

| 材料 | どこで決まったか |
|---|---|
| サイトの目的は**「証拠を置く場所」** | 2026-09-12、本人の言（docs/status.md） |
| `Tailor to the Case`（場に合わせて仕立てる） | プロフィールのキャッチフレーズ |
| `ShowCase` の `case` は多義（事例／容れ物／姓） | 別リポジトリの命名規則より。改名しない理由でもある |
| 色相 265 | デザインシステムのブランド色（`src/tokens/`） |

## 4案

| | 由来 | 16px で何に見えるか |
|---|---|---|
| **A 置き場** | 「証拠を置く場所」をそのまま。上が開いた容れ物に、中身がひとつ入っている | 受け皿・受信箱。意味が直球で、迷いにくい |
| **B 仕立て** | `Tailor to the Case`。四角の角を落とし、落とした分を合わせて置き直してある | **書類アイコンに見える。** 角折れのファイルと区別がつかない |
| **C 容れ物の C** | 頭文字と容れ物を同じ形で兼ねる。開いた口に中身が収まっている | 「C」。名前が直接残るぶん、識別は一番強い |
| **D 重なり** | 「いろいろやっているんだなと思ってもらえるだけで十分」。枚数を形にする | 重なったカード。数の多さは出るが、少し賑やか |

現行は3本の角柱が並んだ形で、上昇するグラフにも読める。由来は記録に残っていない。

## 決め方の目安

- **意味の直球さ**なら A
- **名前としての強さ**なら C
- **「量」を伝えたい**なら D
- B は由来は一番きれいだが、**読まれ方が由来と違う**。直すなら角の処理を変える必要がある

色は2色（インク＋ブランド）に揃えてある。ダーク配色では自動で反転する前提で、
`fill` を直書きしているので、採用時は `currentColor` に寄せる。
